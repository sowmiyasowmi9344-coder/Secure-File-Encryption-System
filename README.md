# 🔒 Secure File Encryption and Decryption System

## 📖 Project Overview

The Secure File Encryption and Decryption System is a cybersecurity mini project developed using Python and Flask. It allows users to securely encrypt and decrypt files through a simple web interface. The project helps protect sensitive files from unauthorized access using modern cryptographic techniques.

---

## ✨ Features

* Encrypt files securely
* Decrypt encrypted files
* User-friendly web interface
* Fast and secure processing
* Easy to use

---

## 🛠️ Technologies Used

* Python
* Flask
* Cryptography Library
* HTML
* CSS

## 🚀 How to Run the Project

1. Install Python.
2. Install the required packages:

```
pip install -r requirements.txt
```

3. Run the application:

```
python app_v2.py
```

4. Open your web browser and visit:

```
http://127.0.0.1:5000
```
